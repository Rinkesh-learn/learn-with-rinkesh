=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
Lookup · Beginner

What it does

Searches for a value in the first column of a range, and returns a value from another column in the same row. It's the formula every recruiter expects you to know cold — used constantly for pulling one dataset's details into another, like matching an Employee ID to a name and salary.

Demo

15-second demo video goes here

Parameters

ParameterMeaning
lookup_valueThe value you're searching for
table_arrayThe range that contains the data
col_index_numWhich column (counting from the left of table_array) to pull the result from
range_lookupFALSE for an exact match (almost always what you want), TRUE for approximate

Corporate use case

A payroll analyst has one sheet with Employee IDs and department codes, and another with Employee IDs and salaries. VLOOKUP pulls the salary into the department sheet without manually cross-referencing hundreds of rows by hand.
